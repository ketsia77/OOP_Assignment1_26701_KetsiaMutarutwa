# AUCA_ID — Tax Administration Management System (TAMS)

This ZIP contains the required Java package tree, 2 interfaces, 2 abstract classes, 11 concrete domain classes with the exact six required own fields, 9 custom exception classes, and the required 21-option console menu foundation.

## Compile and run (JDK 8+)
From the AUCA_ID folder:
```bash
javac -d out -sourcepath src src/com/auca/main/Main.java
java -cp out com.auca.main.Main
```

## Important completion notice
This is a **compileable project foundation, not a finished assignment**. The menu routes most operations to workflow placeholders. The four-step smart forms, constructor-based object creation, fixed-array persistence, global uniqueness checks, financial calculations, payment/refund/clearance workflows, reports, and acceptance-test scenarios still need implementation. The assignment requires all menu actions to work, so do not submit this ZIP as a completed solution yet.

All rates and tax rules in the exercise are fictional educational examples, not official tax law.
